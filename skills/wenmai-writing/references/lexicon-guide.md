# 表达库的选用方法

素材按研究与证据、分析与关系、行动与评论、文学与叙述分库。每条含释义、搭配、文体、原创例句和误用边界，可分别用于正式报告、评论或文学叙述。容量是检索范围，不是每篇文章的用词配额。

这些词与表达属于通用中文素材，释义、用法说明和例句为编辑整理，`provenance: editorial` 不表示逐条来自媒体或经过词典核证。47个阅读页面仍由阅读目录单独记录。既有阅读分析与通用词库分开标注，不能把原创例句署给作家。

## 先确定原句要做什么

先写出普通、准确的意思，例如“说明依据”“限定结论”“描述光线变化”。再按关键词和文体查找少量候选；阅读每条的含义和误用边界，选择有明确收益的一项。不能仅依据表达命中检索就直接替换。

```sh
python scripts/query_lexicon.py --query 依据 --genre 学术综述 --limit 6
python scripts/query_lexicon.py --query 光 --genre 散文 --limit 6
python scripts/query_lexicon.py --kind 成语 --genre 评论 --limit 8
python scripts/query_lexicon.py --stats
python scripts/query_lexicon.py --validate
```

路径按本技能根目录计算。查询采用字面匹配，优先表达本身、写作任务、释义和搭配中的命中，降低仅在例句中偶然出现的关键词权重；不提供同义词推断或语义排序。可分别尝试“依据”“证据”“支撑”等词；无结果时回到普通表达，不为了用库而改原意。`--function` 可按条目中的具体任务文字筛选，`--json` 返回结构化结果。

## 检查四个问题

1. 词义和强度是否相同？“考察”“验证”“确证”并非随意互换。
2. 搭配对象是否相合？描写人的成语不能只因形象就用于抽象算法。
3. 文体是否允许？散文中的景物与感情不能替代技术机理，文学词也不能添加作者未有的见闻。
4. 是否比原句更清楚？术语、普通动词与必要重复都可以保留。

候选入句后，阅读相邻句并对照原意。一次可以提出不同风格的少量方案，但要说明它们各自表达什么，而非只按“高级程度”排列。

## 与督查配合

用户已授权独立审查时，将原句、选用条目的ID、候选与上下文交给 `wenmai-review`，逐条审查本轮实际使用的表达。词库全量检查不能代替目标文章中的迁用检查。

修正遇到的问题后复核受影响的句子；没有明确改善时保留原文。先处理小范围能降低返工成本，不意味着自动降低检测分数，也不要求用户对每处常规修改再次许可。
