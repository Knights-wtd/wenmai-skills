# 文学与评论样本的阅读、迁用方法

## 一张阅读卡片

每个样本记录以下信息：

1. 作者、题名、刊物或页面、链接、正文署期。
2. 实际读取范围：完整刊发页、主体片段、刊发节选、合集；获取失败或仅看到摘要另列。
3. 关键位置：章节、段落主题、前一句在做什么、后一句怎样承接。
4. 措辞作用：动作对象、词义强弱、语气、修饰语增加的信息。
5. 句式作用：铺陈、递进、转折、停顿、转场、回扣。
6. 可迁用范围：适合目标文章哪一类段落，以及需要哪些已有材料。
7. 不能迁用的内容：作者亲历、未经核实的数据、文学想象、强判断或不同文体的评价。

读完正文后回看关键段落。摘词须在相应正文找到，不能凭印象把相似成语写入表格。遇到古人书札、诗句或作品内引文，记录实际归属，不能当作当前作者原创。

正文署期与搜索工具元数据冲突时核对页面，分别写明期刊期次和转载日期。不要仅凭URL中的日期认定发稿日期。

## 怎样提取美感

**词语搭配。** 相近动词不完全等义：核查指检查依据；辨析指说明不同条件或解释之间的差别；验证指检验判断是否得到支持。对象不同，选词也要不同。

**句间呼应。** 单句平常也能通过关系形成韵味。先写机制与代价，再写取舍，后句才有收束作用。孤立添加华丽句子会中断这一联系。

**详略与停顿。** 长句容纳条件和层次，短句完成转场或判断。列完复杂度条件后，可用较短一句交代比较范围；无需在每段末尾再写一句泛化评价。

**具体对象。** 文学描写的修饰语常使颜色、力度、时空或感官更可辨。报告中的带宽、观测时长、路径数等限定也承担精度作用，应当保留。抽象的高级修饰并不自动提供信息。

**贯穿意象。** 随笔中一个意象可在不同位置照应；技术报告可用同一研究问题组织各节，例如资源开销分别联系导频、检测和公平比较。技术指标仍须明确说明，不用比喻替代公式或条件。

## 几个容易混用的词

| 表达 | 需要什么对象或关系 | 使用限制 |
| --- | --- | --- |
| 追索 | 沿引文、版本或其他明确线索回到来源 | 不表示已完成全面核查 |
| 钩稽 | 搜寻并联缀分散的材料线索 | 只读一篇文献时通常不需要此词 |
| 对勘 | 两个或以上材料的逐项比较 | 先说明比较了哪些字段或内容 |
| 相互印证 | 不同材料在同一问题上的可比较支持 | 结论与产生它的实验只是依据关系，不能自动称互证 |
| 权衡 | 同一选择带来的收益与代价 | 两方面都应在上下文出现 |
| 定谳、确证 | 足够证据支持的强判断 | 不用于尚拟开展的实验或有限材料的推断 |

所据、据以、之虞是书面表达；一些四字搭配不是成语。词语类别正确只是第一步，仍须检查它是否适合目标段落。

## 本案例的阅读教训

最初科技样本提取曾出现误记，后来回到原文纠正。扩展文学样本后，正文核读、关键段回读与短引核对更完整，但全文改写的检测结果仍反弹。由此保留两项独立工作：确保提取准确，再判断迁用是否恰当。阅读量不能替代第二项。
